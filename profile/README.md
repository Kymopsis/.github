# Kymopsis

**mmWave radar and RF development kits, with open-source example projects.**

Kymopsis sells 60 GHz and 80 GHz radar development kits and RF parts for
engineers, makers and small teams. Each project below is a complete, buildable
example that shows one of our kits doing something useful, with wiring, firmware
and a step-by-step guide.
